Your PC, your call

How Hive keeps your PC safe.

PC control is powerful, so it is built permission-first. Here is exactly what happens when Hive wants to touch your machine.

1

It asks first. Every time.

Before Buddy opens, clicks or types anything, a card shows what it wants to do with Allow / Deny buttons. Nothing runs until you click Allow.

2

Destructive shell is blocked.

Commands that delete, format or modify system files are blocked in the app itself. You can never accidentally Allow one, because Hive can’t send it.

3

Everything is logged.

Every click, keystroke and shell command Buddy performs lands in the audit overlay. Review the full history at any time.

4

Local-first.

Your chats and files live on your machine. Hive only reaches the internet for search and the model itself.

Hard-blocked, no exceptions: deleting files outside the workspace, formatting drives, modifying the registry, killing system processes, and any command Hive classifies as destructive. These never reach the Allow screen; they are refused at the source.

Good to know

Hive, clearly explained.

A few quick answers about the desktop app, the website and where your work lives.

Is Hive a web app?+

No. Hive is a Windows 10/11 desktop app. This website is for product information, docs and getting the app.

Does the website run Hive Sparks or save missions?+

No. Hive Sparks and the Mission Board are features in the desktop app. The preview on this page is only an explanation; it does not submit or store prompts.

Where does the Mission Board save my prompts?+

The board is stored locally in the Hive desktop app on your device. You can export it as JSON for a backup or import it later. It does not sync through this website.

Can Hive control my PC without asking?+

No. PC actions show an Allow or Deny request before they run, and destructive commands are blocked. You stay in control of whether an action happens.

Does Hive need an internet connection?+

Yes, for AI model requests and live web research. The Mission Board itself is stored locally. Check the selected model provider's terms for how it handles requests.
