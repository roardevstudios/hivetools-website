Overview

Hive is a Windows desktop workspace. One window holds a chat column with cited answers, a code canvas, a roster of agent bots, HiveBox, and a system-wide buddy — an orange companion that trails your cursor and pops a notch island with Ctrl + Shift + J.

Local-first. Chats, settings, and transcripts live on your machine.

Workspace UI

Hive features a minimalist pro-tool interface designed around high density and deep focus. The interface is composed of four primary columns:

  • Icon Rail — Quick access to Workspace Chat, agent tools, projects, and settings.
  • Collapsible Conversation Panel — Filter chats, jump between active threads grouped by date, or launch a new conversation instantly. Toggle with Ctrl + B.
  • Pro Chat Stream & Tactile Composer — Clean conversation thread with thinking indicators, inline code preview, file attachments, and tactile interactive send controls.
  • Crew Panel — Slide-out workspace drawer for live code inspects, markdown files, browser steps, and tool outputs.

Chat & search

Your messages render as right-aligned bubbles; assistant replies are full-width. Words like search, latest, news, who is, lookup trip the web pipeline. Answers arrive with Verified Sources cards: domain, title, snippet, links.

The mode pill in the title bar is Fast, Auto, Heavy, or Max — Hive picks the model for you.

Buddy

  • Messages — every assistant reply carries the orange house avatar.
  • Cursor — trails the mouse across screens with spring physics and a click-pop.
  • System window — click-through, always on top, hides when Hive hides.

Recolor it in Settings → Buddy Color: Orange, Ink, Ghost, Cobalt, Amber.

Notch & hotkeys

Press Ctrl + Shift + J anywhere — even with Hive minimized. A black pill pops at the top of your screen and opens into the Buddy panel. Dictate with the mic, type a question, or run slash commands. Esc dismisses. Tray → Ask Hive opens the same notch.

PC control

Hive is designed with a strict human-in-the-loop permission flow. Operator waits for your explicit Allow / Deny approval before opening apps, running commands, moving the cursor, or typing. Destructive shell commands are blocked by security policy, internal reasoning remains private, and every action is recorded in the overlay audit log.

CommandDoes
/open <app|url>Launches apps or URLs
/run <powershell>Runs a shell command, returns output
/click <x> <y>Moves the cursor and left-clicks
/type <text>Types into the focused window

Swarm & bots

Scout, Hive, and Pulse start together on one message. Critic only runs after Hive answers. Sentry watches tool calls and rewrites fake citations or destructive commands. A swarm strip appears when two or more agents overlap.

Command palette

Ctrl + K opens the palette: new chat, group, Buddy, canvas, settings, workers, notch.

HiveBox

The right-side panel is a live view of HiveBox: a tiny disk, logs, and concurrent Scout / Hive / Pulse jobs. Toggle it in the title bar. Commands: ls, cat, echo, pwd, uname.

FAQ

Windows only?

Yes, today — the buddy click/type engine is Windows-native.

Is it free?

The Hive Public Beta has been taken down and the v0.0.1 installer is no longer available from this website. Future release details will be posted on the changelog.

Where is my data?

On your machine: chats and settings in local storage. The website keeps only auth + profile rows.

The buddy vanished!

It hides with the app by design — show Hive and it returns.

Security & Account Safety

Hive uses Supabase for sign-in and account storage. Your browser keeps the active session locally so you stay signed in across Hive pages; you can sign out from your profile at any time.

Keeping your account safe

  • Use a unique password and do not share your sign-in session.
  • Sign out on shared or public computers after using your account.
  • Contact apis.new.world@gmail.com if you see unexpected account activity.

For password recovery, use Forgot password? on the sign-in page.

What we collect
